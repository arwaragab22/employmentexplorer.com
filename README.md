# 🌐 Employment Explorer

**Employment Explorer** is an interactive web application designed to help users explore job opportunities, trends, and career paths in various industries. The project uses a dynamic and engaging UI, providing users with a seamless browsing experience.

---

## 🧩 About the App

The application is built using **HTML**, **CSS**, **JavaScript**, and **jQuery**, with added functionality and interactivity provided by **Panzoom.js** for zoomable content. I worked on creating the **Classic Explorer** section, which allows users to visually navigate through career options and opportunities. 

---

## 💻 Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**  
- **jQuery**  
- **Panzoom.js** (for zoomable interactive content)
- **CSS Animations** (for smooth transitions and interactive elements)

---

## 👩‍💻 My Role

I was responsible for developing the **Classic Explorer** section, which involved:

- Implementing the user interface using **HTML** and **CSS**  
- Adding interactivity and dynamic behavior with **JavaScript** and **jQuery**  
- Integrating **Panzoom.js** for zoomable features on specific content  
- Creating and optimizing animations for a smooth and engaging user experience
